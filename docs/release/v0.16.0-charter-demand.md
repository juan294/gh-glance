## Finding DEMAND-01

**Severity: medium. Local disposition: confirmed behavioral defect, return to the parent for remediation and fresh candidate evidence. No fix was made during this charter.**

Reproduction against the immutable installed entry:

1. Run the isolated packed entry with `--repo acme/widget --refresh 2 --tab issues`, using the fake `gh` fixture.
2. Wait until the capture contains `Cached`.
3. Leave the session idle for 16 seconds, then send `q`.
4. Read the final terminal frame and the successful source-response timestamp from the independent fixture ledger.

Exact executable command:

```sh
node /Users/juan/code/gh-glance/docs/agents/release-0.16.0-2026-10-01/charter-demand/confirm.mjs > /Users/juan/code/gh-glance/docs/agents/release-0.16.0-2026-10-01/charter-demand/confirm.log 2>&1
```

The script's `age-confirm` leg records its complete `capture` options and exact stdin sequence in `age-confirm.json`. Its producer waits for `Cached`, executes `sleep 16`, then `printf q`. It executes the packed application; only the external `gh` seam is synthetic. The recorded source response ends at Unix-ms `1790859370008`; the capture ends at `1790859386260`, a difference of **16252 ms**. Final footer: **`· Cached 0s`**. There is exactly one `issues.page` start and successful completion, so no refresh can explain the zero-age claim. The correct elapsed age at exit is approximately 16 seconds.
