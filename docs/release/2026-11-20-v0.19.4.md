## Accepted limitations

- F12 personal and work EMU qualification: open.
- Known limitations of v0.19.3 are unchanged.
- From the independent review, low severity, none a regression:
  - A remote whose `gh-resolved` value names another repository changes the target for single-remote checkouts too, matching `gh`. This is documented in the release notes.
  - Non-GitHub remotes and case variants of one slug (`Me/X` and `me/x`) count as separate repositories and show the choice screen. Before, the same checkouts failed with a misleading error. `gh repo set-default` clears it.
  - `--doctor` can label a remote "gh default" when its `gh-resolved` value is malformed and was ignored by selection. Cosmetic.
  - After `gh repo set-default`, the dashboard needs a restart to pick up the choice.
