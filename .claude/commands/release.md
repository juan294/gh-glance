# Release New Version

Follow the project release procedure in
[`docs/release/release-playbook.md`](../../docs/release/release-playbook.md).
It is the single authority for gh-glance releases, including what supplied
authority covers, the corrective allowance and failure handling; this command
only routes there. Use the version already supplied in the request and ask for
one only if it is absent; never guess or auto-increment.
